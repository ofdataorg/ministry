The condition flag is applied by rule

  • broken the download failed, or returned a file with no rows.
  • attention it served data, but at least one of: a wholly empty column, a broken cadence promise, or no licence stated.
  • serviceable none of the above applied when we measured it.

These are measurements, not evaluations. No six-axis grade is given because nobody has read them and formed a judgement — a machine downloaded each one and wrote down what happened. They are deliberately excluded from The Index, which scores only reviewed datasets.
